# TA plugin naming

Use **TA <Tool Name>** for public QGIS plugin names, including **TA Work Log**
and **TA Task Workspace**. Include `ta` and `terraanalytica` search tags.

The shared header retains the TerraAnalytica wordmark and a short functional
title. Menus, Plugin Manager entries and help use the prefixed product name.
Existing Python package IDs and persistent database/settings identifiers remain
stable when a public name changes.
